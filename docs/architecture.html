One investigation, end to end

Verified live with CVE-2021-44228 (Log4Shell) and CVE-2021-45046.

  1. Validate IOC. Per-type regex or ipaddress, normalised (CVE upper, domain lower). Injection strings get 422.
  2. Researcher runs a ReAct sub-agent capped at 10 tool calls, plus a direct KB retrieval so every report has citations.
  3. Critic returns APPROVED or a gap list; it can send work back once.
  4. Reporter streams the report token by token as report_chunk.
  5. Persist. Embed report → save to Postgres → pgvector finds similar past reports.
  6. done event carries report_id, sources, tool trail and similar reports.

Production roadmap

Phase 4B · Run it safely

next
  • LLM gateway: fallback chain, credit-aware readiness probe, token budgets per tenant
  • Identity: OIDC + RBAC (analyst / engineer / admin); tenant ID on rows and Qdrant payloads
  • State: Redis for sessions, ingest jobs and rate limits; today all three are lost on restart
  • Workers: Arq or Celery for ingestion and long investigations
  • Observability: Langfuse traces (keys already in env), OpenTelemetry, audit log
  • Guardrails: classifier-based injection detection; technique-ID validation against MITRE
  • CI/CD: ruff, mypy, pytest ≥80%, web build, Trivy, Playwright on the compose stack

Phase 4C · SOC value

after 4B
  • IOC enrichment: VirusTotal, AbuseIPDB, OTX, GreyNoise, WHOIS. IP, hash and domain cases have no real data source today
  • Scheduled feeds: CISA KEV daily, NVD deltas, MITRE quarterly, STIX/TAXII
  • Hybrid retrieval: BM25 + dense + rerank, exact match on T1059.001-style IDs
  • Export: STIX 2.1 bundle, PDF, Jira / ServiceNow tickets, Slack alerts
  • SIEM hook: Splunk / Sentinel alert triggers an investigation automatically
  • Feedback loop: analyst edits critic gaps; 👍/👎 feeds a golden eval set in CI
